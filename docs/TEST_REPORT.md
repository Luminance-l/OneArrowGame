## 缺陷发现与修复

1. **第 5 关不可解**：BFS 首次返回 `None`。定位为阻挡环，将 `(3,1)` 从向上改为向左后，完整 24 步解通过。
2. **测试夹具坐标错误**：初版 T02 选择了无遮挡的 `(3,3)`。改用 `(2,2)` 后准确覆盖右侧阻挡。
3. **按钮出现方框字**：中文系统字体缺少部分装饰符号。改为纯中文按钮文本并重新截图。
4. **结算页计时继续增长**：新增 `finished_elapsed`，成功或失败时冻结本局用时。
